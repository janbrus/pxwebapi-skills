generic-pxweb-v1-skill

The skill guides AI agents like Claude and ChatGPT through finding, fetching and presenting official statistics from any PxWebApi v1 installation, the older API that most PxWeb agencies still run. In v1, data comes back only from a POST. The first diagram shows the workflow in a conversation. The second shows how the package is verified and built into a zip.

Base rule
Never state a number you have not fetched from the API in this conversation.

The highlighted line in the diagram below is the only way a number can enter the answer.
