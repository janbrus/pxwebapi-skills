generic-pxweb-v2-skill

The skill guides Claude through finding, fetching and presenting official statistics from any PxWebApi v2 installation. Statistics Norway, Statistics Sweden and Latvia’s CSP are verified. The first diagram shows the workflow in a conversation. The second shows how the package is verified and built into a zip.

Base rule
Never state a number you have not fetched from the API in this conversation.
